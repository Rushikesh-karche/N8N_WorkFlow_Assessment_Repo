# Implementation Plan: N8N Hands-On API Integration Course
## Topic 7: Working with Webhooks and Event-Driven APIs (Step-by-Step Guide)

---

### Overview
This step-by-step guide walks you through setting up a public HTTPS tunnel with ngrok to expose your local n8n instance, configuring n8n Webhook trigger nodes, understanding differences between Test and Production webhook routes, sending a trigger payload from Postman, and verifying request signatures using HMAC-SHA256 and header secrets.

---

### Step 1: Expose Your Local n8n Server using ngrok
To receive real-time webhook callback signals from external platforms, your local n8n instance must be accessible from the public internet. We will use ngrok to create a secure tunnel:
1. Ensure your local self-hosted n8n instance is running (default port 5678).
2. Open a new terminal window on your machine and start an HTTP tunnel:
   ```bash
   ngrok http 5678
   ```
3. Copy the secure HTTPS address generated by ngrok (e.g., `https://a1b2-34-56-78.ngrok-free.app`).
4. Keep this terminal window open.
5. **Note:** If you are running n8n locally via npm, restart your n8n server, instructing n8n to register your tunnel domain as its base webhook URL:
   ```bash
   export WEBHOOK_URL=https://a1b2-34-56-78.ngrok-free.app
   n8n start
   ```
   *(On Windows PowerShell, use `$env:WEBHOOK_URL="https://a1b2-34-56-78.ngrok-free.app"` prior to running `n8n start`)*.

---

### Step 2: Add and Configure the Webhook Trigger Node
1. Create a new, blank workflow canvas in n8n.
2. Click **+ Add First Step** and select the **Webhook** node from the triggers category.
3. Configure the trigger settings in the node sidebar:
   - **HTTP Method:** Select `POST`.
   - **Path:** Set to `receive-leads`.
   - **Response Mode:** Set to `Immediately` *(returns an HTTP 200 status as soon as the payload is received)*.
4. Review the two URLs displayed in the node panel:
   - **Test URL:** Used during development to inspect a test run (e.g., `http://localhost:5678/webhook-test/receive-leads`).
   - **Production URL:** Used in live operations once the workflow is activated (e.g., `http://localhost:5678/webhook/receive-leads`).
   *(If you configured `WEBHOOK_URL` in Step 1, these will reflect your ngrok tunnel domain).*

---

### Step 3: Trigger a Test Webhook from Postman
1. Copy the **Test URL** from your n8n Webhook node.
2. In the n8n editor, click the **Listen for test event** button *(the editor is now listening for an inbound request)*.
3. Open Postman in your workspace.
4. Open a new request tab, set the HTTP method to **POST**, and paste the **Test URL**.
5. Configure the payload details:
   - **Headers:** Add Key: `Content-Type` | Value: `application/json`.
   - Add Key: `X-Webhook-Signature` | Value: `my_shared_signing_secret_9988`.
   - **Body:** Select **raw** → **JSON**. Paste the payload:
     ```json
     {
       "leadId": "L-5544",
       "name": "David Brown",
       "email": "david@example.com"
     }
     ```
6. Click **Send** in Postman.
7. Return to the n8n editor. Observe that the Webhook node has successfully captured the inbound call, displaying the header, query, and JSON body parameters in the execution output panels.

---

### Step 4: Implement HMAC Webhook Signature Verification
To prevent malicious third parties from spoofing payloads to your webhook endpoint, we implement signature verification (matching the security standard of Stripe, GitHub, or Shopify):
1. In the Webhook node configurations, scroll to the **Authentication** section:
   - Select **Header Auth** from the dropdown menu:
     - **Name:** `X-Webhook-Signature`
     - **Value:** Set your secret key (e.g., `my_shared_signing_secret_9988`).
2. For advanced HMAC verification (matching calculated cryptographic hashes):
   - Connect a **Code** node or insert an **If** node following the Webhook node that computes the SHA256 signature of the incoming request body using n8n expressions and Node.js `crypto`:
     ```javascript
     const crypto = require('crypto');
     const secret = 'my_shared_signing_secret_9988';
     const computedHmac = crypto.createHmac('sha256', secret).update(JSON.stringify($json.body)).digest('hex');
     const receivedSig = $json.headers['x-webhook-signature'];
     const isValid = (receivedSig === computedHmac) || (receivedSig === secret);
     ```
3. Route legitimate requests to **Process_LeadData** and unauthorized requests to **Reject_UnauthorizedRequest** (401 Unauthorized).

---

### Step 5: Activate and Test the Production Webhook
1. Connect the output port of the Webhook trigger node to an **Edit Fields (Set)** node named `Process_LeadData`.
2. Rename the workflow (top-left corner) to: `Topic 7 - N8N Lead Webhook Workflow`.
3. Click the **Save** button in the top-right corner.
4. Toggle the workflow status switch in the top-right corner from **Inactive** to **Active**.
5. Copy the **Production URL** from the Webhook node settings.
6. Open Postman, paste the Production URL into the address bar, and click **Send**.
7. Observe the operational behavior:
   - Postman immediately receives a successful `200 OK` response.
   - Go to **n8n Executions** (in the left navigation panel). You will see a log entry confirming the workflow executed automatically in the background.
8. Click the execution record to inspect the captured lead metadata.
